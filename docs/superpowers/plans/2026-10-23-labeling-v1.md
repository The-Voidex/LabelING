# LabelING v1 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个本地运行的图像标注 Web 应用，支持导入数据集、基于提示词的模型预标注、人工审核修改，并导出 YOLO/COCO。

**Architecture:** 单进程 FastAPI（API + 静态前端 + SQLite + 本地文件）与 React SPA；预标注通过可插拔 Provider 调用 OpenAI 兼容视觉模型，asyncio 后台任务持久化进度，前端轮询。坐标归一化存储，三态审核（未标注/待审核/已确认），AI 框与人工框分离。

**Tech Stack:** Python 3.13、uv、FastAPI、SQLModel、SQLite(WAL)、Pillow、httpx、pytest；React 19、TypeScript、Vite、Tailwind CSS v4、TanStack Query、Zustand、react-konva、Vitest。

**Spec:** `docs/superpowers/specs/2026-10-23-labeling-design.md`

## Global Constraints

- 所有用户可见文案必须为中文（按钮、菜单、提示、错误、空状态、导出 README）；代码标识符与内部日志可为英文。
- 服务仅监听 `127.0.0.1`；后端端口 8000，前端开发端口 5173。
- 数据库坐标一律存归一化值（0–1，左上到右下）。
- 图片状态：`unlabeled` / `labeled` / `confirmed`；框来源：`ai` / `human`。
- 预标注重跑只替换 AI 框，人工框永久保留；确认时 AI 框全部转为人工框。
- 所有 JSON API 请求需带 `X-LabelING-Client: web`；图片文件、缩略图、导出下载豁免。
- 测试不调用真实模型接口，统一使用 Mock Provider；不静默安装 Playwright 浏览器。
- 工作区当前不是 git 仓库，未获得用户明确授权前不执行任何 git 初始化或提交。

```python
def create_engine_for(settings: Settings) -> Engine:
    settings.data_dir.mkdir(parents=True, exist_ok=True)
    url = f"sqlite:///{settings.data_dir / 'labeling.db'}"
    engine = create_engine(url, connect_args={"check_same_thread": False, "timeout": 5})
    @event.listens_for(engine, "connect")
    def _pragma(dbapi_conn, _):
        cur = dbapi_conn.cursor()
        cur.execute("PRAGMA journal_mode=WAL")
        cur.execute("PRAGMA foreign_keys=ON")
        cur.execute("PRAGMA busy_timeout=5000")
        cur.close()
    return engine

def init_db(engine: Engine) -> None:
    SQLModel.metadata.create_all(engine)

def get_session(request: Request) -> Iterator[Session]:
    with Session(request.app.state.engine) as session:
        yield session
```

- [ ] **Step 3: 写 API 客户端**

```ts
export class ApiError extends Error {
  constructor(message: string, public status: number, public code?: string) { super(message); }
}

export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const headers = new Headers(init.headers);
  headers.set("X-LabelING-Client", "web");
  if (init.body && !headers.has("Content-Type")) headers.set("Content-Type", "application/json");
  const res = await fetch(`/api${path}`, { ...init, headers });
  if (!res.ok) {
    const data = await res.json().catch(() => null);
    throw new ApiError(data?.error?.message ?? `请求失败（${res.status}）`, res.status, data?.error?.code);
  }
  if (res.status === 204) return undefined as T;
  return res.json();
}
```
